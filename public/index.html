easysmarky

Smarkyのデジタルレポート入力を楽にするスクリプトを配信しています。 導入方法は Android アプリ・ユーザースクリプト版・ブックマークレット版の3通りあり、どれか1つでかまいません。

  • Android アプリ(入れて開くだけ): easysmarky-arm64-v8a.apk — 約100MB。入れ方は README をご覧ください
  • ブックマークレット版: easysmarky.iife.js
  • ユーザースクリプト版(Tampermonkeyなど): easysmarky.user.js — インストール後は自動で更新されます

使い方・登録手順は GitHubリポジトリのREADME をご覧ください。
